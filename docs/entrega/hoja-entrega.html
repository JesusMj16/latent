Descripción del proyecto

El programa lee imágenes en escala de grises en formato PGM P2 (texto), les aplica filtros (negativo, brillo, umbral, espejos, rotaciones, desenfoque 3x3 y cadenas de filtros) y las comprime con RLE, comprobando que al descomprimir se recupera la imagen original. Todo el procesamiento está escrito en Haskell como funciones puras sobre listas de listas; una interfaz en Python tkinter solo elige el archivo, lo envía por socket al servidor Haskell y muestra el resultado.

Semblanza técnica

  • Haskell (GHC 9.10): núcleo funcional puro en src/: Image (tipos, applyPixel, applyChain), Image.Pgm, Image.Pointwise, Image.Geometry, Image.Compression, Image.Convolution y Protocol (handleRequest :: String -> String). El IO vive solo en app/Server.hs y app/Main.hs.
  • Python tkinter: solo interfaz; no calcula nada sobre los píxeles.
  • Comunicación: socket TCP en 127.0.0.1:5000, una petición por conexión (comando + PGM; respuesta IMAGE, STATS o ERROR).
  • Técnicas: recursión, map, zipWith3, span, composición, aplicación parcial, pattern matching, guardas, Maybe y Either. 35 pruebas.
  • IA usada: Claude Code (extensión de VS Code) con el modelo Claude Opus 5.5 de Anthropic, como compañero de desarrollo. Las funciones base (onRows, width, height, parsePgm, renderPgm, readPgm, writePgm) las escribí yo. Prompt (resumido):

Respeta mis funciones, completa el núcleo puro en Haskell (filtros, RLE, protocolo String -> String), un servidor por sockets delgado y una GUI tkinter que solo sea interfaz, sin IORef ni mónadas avanzadas, con firmas de tipo y comentarios en español."
