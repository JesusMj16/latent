Descripción del proyecto

Este programa toma una imagen en escala de grises guardada como texto, en formato PGM P2, y la transforma: puede invertir sus tonos, aclararla, pasarla a blanco y negro, reflejarla, girarla, desenfocarla o aplicarle varios filtros seguidos. También la comprime con RLE y comprueba que al descomprimirla sale idéntica. Todo el trabajo lo hace Haskell con funciones puras; Python solo pone la ventana.

Semblanza técnica

  • Haskell hace todo el trabajo. El núcleo vive en src/ y son funciones puras: reciben datos y regresan datos, sin tocar archivos ni la red. Los módulos son Image, Image.Pgm, Image.Pointwise, Image.Geometry, Image.Compression, Image.Convolution y Protocol, cuya función handleRequest :: String -> String resume todo el protocolo. Solo app/Server.hs y app/Main.hs leen archivos o usan la red.
  • Python con tkinter solo dibuja la ventana. Elige el archivo, lo manda y muestra lo que regresa. No calcula nada sobre los píxeles.
  • Se comunican por un socket TCP en 127.0.0.1:5000. Python manda una línea con el comando y debajo la imagen; Haskell contesta con la imagen nueva, con las estadísticas de compresión o con un mensaje de error.
  • Ideas funcionales que usa: recursión, map, zipWith3, span, composición, aplicación parcial, pattern matching, guardas, Maybe y Either. Tiene 35 pruebas automáticas.
  • Uso de IA: trabajé con Claude Code dentro de VS Code, con el modelo Claude Opus 5.5 de Anthropic, como compañero de desarrollo. Yo escribí las funciones base: onRows, width, height, parsePgm, renderPgm, readPgm y writePgm. Este fue el prompt, resumido:

"Eres mi compañero de desarrollo para terminar el proyecto final de Programación funcional. Respeta mis funciones y completa el núcleo puro en Haskell con los filtros, la compresión RLE y un protocolo de texto a texto, un servidor por sockets que solo mueva bytes y una ventana en tkinter que solo sea interfaz. Nada de estado mutable, cada función con su firma y un comentario en español."
